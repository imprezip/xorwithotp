# CryptoLab: XOR Stream Cipher \& One-Time Pad

**Try it online:** https://xorwithotp.vercel.app/

CryptoLab is an interactive web application for learning XOR encryption, decryption, One-Time Pad (OTP), and key reuse attacks. It provides step-by-step visualizations to help users understand how XOR-based cryptography works.

## Features

* **XOR Cipher:** Encrypt and decrypt using Text, Hexadecimal, and Binary formats.
* **Show Steps:** Visualize byte conversion, binary representation, and XOR operations.
* **Exercise Mode:** Practice predefined test cases and check answers.
* **Key Reuse Attack:** Demonstrate why reusing the same key is insecure, including a known-plaintext attack.
* **OTP Mode:** Generate cryptographically random keys and explore One-Time Pad requirements.
* **Interactive UI:** Responsive design, dark/light themes, and an animated constellation background.

## Tech Stack

React, TypeScript, Vite, Tailwind CSS, Lucide React, and Vitest.
